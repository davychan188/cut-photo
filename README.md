# 裁相

用瀏覽器裁剪相片，並自動把原本拍攝日期時間（EXIF）印返去已裁相片上。格式預設同 Canon 相機，例如 `19 08 2026 11:31`。原相片唔會被改動。

而家版本係 **1.2.1**（網頁左上角會顯示「版本 1.2.1」）。

**網上使用：** [https://davychan188.github.io/cut-photo/](https://davychan188.github.io/cut-photo/)

建議用 **Chrome 或 Edge** 打開，大量處理時就可以直接存入電腦資料夾。

## 大量處理（建議流程）

1. 用 Chrome 或 Edge 打開上面嘅網頁
2. 「開啟資料夾」載入全部相片
3. 「揀輸出資料夾」選一個用來放裁好相片嘅資料夾（建議同原圖分開）
4. 每張相會出現一個同原圖比例嘅框，可移動或用「框大細」縮放；需要嘅話可「套用此框到未裁相片」
5. 按 **Enter**（或撳「儲存並下一張」）儲存。預設會輸出回原圖像素大細，型狀同原圖一致
6. 檔案會即時寫入該資料夾，檔名係 `原檔名_crop.jpg`，然後自動跳下一張

揀一次資料夾就得，之後唔使再確認、亦唔會一張張彈下載。

如果瀏覽器唔支援直接寫入資料夾，可以用「全部匯出 ZIP」，一次過下載已拉框嘅相片。

## 本機打開

也可以下載 `index.html`（或 `裁相.html`）雙擊打開。不過直接開本機檔案時，瀏覽器通常唔允許寫入資料夾，大量儲存會較麻煩；網頁版就冇呢個限制。

## 快捷鍵

- 左右方向鍵：上一張／下一張
- 滾輪：縮放；按住空白鍵拖移相片
- Enter：儲存並下一張
- Esc：標註模式先取消選取圖形；拉框模式重設裁剪框
- Delete／Backspace：刪除已選圖形
- Ctrl+Z／⌘Z：上一步；Ctrl+Y 或 Ctrl+Shift+Z：重做

日期來源優先用 EXIF 拍攝時間；如果相片沒有 EXIF，就用檔案修改時間，亦可喺右邊人手改印字、位置、顏色同字級。

## 裁剪框

預設「固定原圖比例」同「輸出用回原圖尺寸」會開住，避免裁完之後每張相比例同大細都唔同。你可以用「框大細」設定框佔原圖幾多，再喺相片上移到要嘅位置。

## 標註圖形

右邊可切換「拉框」同「標註」。標註模式可以喺相片上加箭咀、直線虛線、弧型虛線同圓圈：

- 拖曳嚟畫新圖形，大細同顏色都可以調（箭咀嘅線同箭頭會一齊放大縮細）
- 拉住圖形就可以移動；拉住白點可以改方向、長度或形狀
- 撳「刪除此圖形」，或按 Delete／Backspace 刪除已選圖形
- 圖形以原圖像素座標儲存，會跟住相片內容，移動裁剪框唔會帶走佢哋
- 匯出（單張儲存、寫入資料夾、ZIP）時會把圖形印喺裁好嘅相片上，然後先印日期時間，避免日期被遮住。裁剪框以外嘅部份會被切走
- 「套用此框到未裁相片」只會套用裁剪框，唔會複製標註
- 「上一步」（Ctrl+Z）可以還原標註同裁剪框嘅改動，「重做」可以再套返；每張相分開記住
